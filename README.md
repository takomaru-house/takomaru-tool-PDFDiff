# PDF差分検出ツール — モックアップ＆サンプル

Claude Code 着手前の事前検証用パッケージ。仕様確認とアルゴリズム動作の確認を目的とする。

## ファイル一覧

| ファイル | 説明 |
|---|---|
| `SPEC.md` | 仕様書本体（Claude Code への依頼内容） |
| `index.html` / `pdfDiff.css` / `pdfDiff.js` | 本体一式(pdf.js 使用)。ブラウザで `index.html` を直接開けば動作。 |

## 比較フロー (UI操作)

1. **ファイル選択**: ヘッダーの Before / After にPDF（または画像）をそれぞれセット。
2. **ページ範囲確認**: ファイル読み込み後、黄色いバーが表示される。Before / After それぞれの「開始〜終了ページ」を入力（デフォルトは全ページ）。
   - 例: Before 1〜5、After 2〜6 のように、ページ数や始点が違っても比較可。
   - 両側の範囲長は一致する必要がある（バーに対象ページ数が表示され、不一致なら赤色警告 + 「比較を実行」ボタン無効化）。
3. **比較を実行**: ボタンを押すと差分計算が始まる。完了後、左サイドバーに差分リストが、中央にビューアが表示される。
4. **表示モード切替**: 並列／重ね合わせ／差分のみ。重ね合わせモードでは After の透過率を調整可。
5. **差分箇所へジャンプ**: 左の差分リストをクリックすると、該当箇所が画面中央へ移動＋黄色く一瞬パルスして強調される。
6. **エクスポート**: ヘッダー右の「JSON出力」「HTMLレポート出力」で結果を保存可能。

## ビューア操作

ステージ（中央のキャンバス領域）では、以下のマウス操作が使える。

| 操作 | 動作 |
|---|---|
| 左ドラッグ／右ドラッグ | パン（移動） |
| ホイール | カーソル位置を中心に拡大／縮小 |
| ダブルクリック | 表示倍率と位置をリセット（自動フィット） |

ツールバーの「− / ＋ / フィット」ボタンも同じビューに作用する。

## モックアップの起動

`index.html` をブラウザでダブルクリック(`file://` 直開き)で動作する。ローカルサーバーは不要。

- 自分のPDFをファイル選択で渡す動作 → サーバー不要
- サンプルPDFボタン → サンプルデータを `samples/samples_data.js` (Base64) として別ファイルに同梱しており、`file://` でも `<script>` 動的注入で読めるためサーバー不要

ローカルサーバーが必要なケースは特にないが、複数端末から同時アクセスしたい場合のみ任意で `python -m http.server 8765` 等で起動する。

## モバイル(スマホ)対応

- 幅 ≤ 820px で縦2段スプリットレイアウト(上: PDFビュー / 下: 差分索引)。
- 比較完了後はファイル選択行・比較範囲バーを自動的に折りたたみ、ビュー領域を最大化。再変更したい場合はヘッダの「✎ 編集」をタップ。
- ステージ上のタッチ操作: **1本指ドラッグ=パン / 2本指ピンチ=ズーム / ダブルタップ=FIT**。
- iOS Safari (15+), Android Chrome 最新2世代で動作確認。
- 詳細は `SPEC.md` §14 を参照。

## サンプルに仕込んだ差分（20ページ構成）

サンプルは Before / After ともに **20ページ** あり、差分は複数ページに分散して仕込んである。
全ページに「Page N / 20」のヘッダがあり、After 版のヘッダ更新も差分として検出される。

### 表データ (table) — 20カテゴリの製品マスタ
| Page | カテゴリ | After 側の変更内容 |
|---|---|---|
| 2 | 周辺機器 | B-101 単価変更 / B-205 USB-Cドック を行追加 |
| 4 | オーディオ | D-402 USBスピーカー削除 / D-406 Bluetoothスピーカー追加 |
| 7 | 入力機器 | G-704 テンキー在庫変更 (80 → 30) |
| 10 | プリンタ | J-1003 商品名変更（A3 大判インクジェット (新)）|
| 14 | オフィス家具 | N-1402 ゲーミングチェア値下げ (28,800 → 32,800) |
| 17 | 防災用品 | Q-1701 在庫数変更 / Q-1704 商品名変更 |
| 20 | 廃棄物管理 | T-2004 古紙回収ボックス を行追加 |

### 間取り図 (floorplan) — 20号室分の住宅図面（101〜120号室、奇数=1LDK / 偶数=2LDK）
| Page | 号室 | After 側の変更内容 |
|---|---|---|
| 2 | 102 | 縦寸法 6,800 → 7,200 |
| 4 | 104 | 和室 → 洋室 |
| 7 | 107 | 中央壁 右へ移動（寸法 5,940 → 6,240 / 4,860 → 4,560） |
| 9 | 109 | LDK 16帖 → 18帖 |
| 12 | 112 | 寝室1 を分割しクロゼット新設 / 縦寸法変更 |

`samples/diff_result_*.png` を見ると、これらの差分が紫色の枠で検出されていることを確認できる。

## モックアップが満たしている要件

- 2つのPDF/画像を **ブラウザだけで** 比較（API・サーバー不要）
- 視覚（ピクセル）差分の検出 → bbox を SVG オーバーレイで表示
- テキスト差分（pdf.js のテキスト抽出 × 領域マッチング）
- 3つの表示モード（並列 / 重ね合わせ / 差分のみ）
- 重ね合わせ時の透過率スライダー
- 差分リスト ⇄ ハイライト枠 の連動フォーカス（クリックで該当箇所へ移動・パルスアニメ）
- 差分結果の JSON / HTML エクスポート
- 拡張仕様: 画像ファイル（PNG/JPEG/WebP）入力にも対応
- キーボードショートカット（←/→ ページ送り、J/K で差分送り、Space でチェックトグル）
- 差分のレビューチェック機能(`SPEC.md` §13) — 各差分にチェックを付け、未チェックのみのレポート出力が可能
- モバイル(スマホ)対応(`SPEC.md` §14) — 縦2段レイアウト・タッチ操作・ヘッダ自動圧縮
